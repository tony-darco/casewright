The look of software that has to be right.

A quiet, technical system for a tool that turns specifications into working test code. Warm off-white paper, never-black ink, hairline rules instead of shadows, and a sans + monospace pairing — because the mono isn't a style here, it's the product's material. No color at all: hierarchy is carried by space, weight, and rule; pass and fail by symbol.

Palette 7 tokens / 0 hue

White, a warm off-white ground, and a warm near-black laddered by opacity. No accent, no tint — the warmth is the only "color," and it's what keeps grayscale from feeling cheap.

# spec — feature
Given an empty cart
When the user adds a
  $40 item and applies
  code "SAVE10"
Then the order total
  is $36.00
And the discount line
  reads "-$4.00"
test("applies SAVE10 to a $40 cart", async () => {
  const cart = await newCart();
  await cart.add(item({ price: 40 }));
  await cart.apply("SAVE10");

  expect(cart.discount).toBe(-4.00);
  expect(cart.total).toBe(36.00);
});
